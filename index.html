How the course works

A predictable routine for each module

Use the same four compact steps from the first reading to the saved evidence.

1. Read

Read each section in the order shown and use the provided references.

2. Practise

Complete guided checks to verify safety and accuracy before the next step.

3. Capture

Use scaffolded responses to write what you checked and what you will improve.

4. Save

Download each module PDF before moving on or leaving the site.

Student evidence. All data is saved locally in this browser. Keep a PDF backup for school submission and your own reference.
